# vmpanel_os

Поиск по названию без учёта регистра — система из каталога. Не нашлось — ошибка со
списком того, что есть.

## Пример

```terraform
data "vmpanel_os" "this" {
  name = "Ubuntu 24.04"
}
```

## Атрибуты

- `id` — номер для ресурсов провайдера.
- `state` — `available`: систему можно ставить.
