# Провайдер Terraform vmpanel

Машины, вебхуки и справочники панели как код. Работает через совместимый API
`/vm/v3` и ключ API, поэтому подходит всем:

- **клиенту хостера** — ключ видит только его машины;
- **сотруднику хостера** — парк его организации;
- **владельцу платформы** — всю платформу.

## Подключение

1. Выпустите ключ API: «Настройки» → «Ключи API» (клиент хостера —
   `POST /vm/v3/api_key`, владелец — «Платформа» → «Ключи API платформы»).
2. Передайте адрес панели и ключ через переменные окружения:

```bash
export VMPANEL_ENDPOINT=https://panel.example.ru
export VMPANEL_API_KEY=vtk_…
```

или в блоке `provider "vmpanel" { endpoint = …, api_key = … }`.

Пример целиком — [examples/main.tf](examples/main.tf).

## Ресурсы

### `vmpanel_vm`

| Поле | | Смысл |
|---|---|---|
| `name` | обязательно, пересоздание | имя: латиница, цифры, `-`, `.` |
| `os_id` | обязательно, пересоздание | `data.vmpanel_os.<…>.id` |
| `location_id` | пересоздание | `data.vmpanel_location.<…>.id`; не задана — первая доступная |
| `preset_id` | пересоздание | тариф; задаёт ядра, память, диск, если они не указаны |
| `cpu`, `ram_mib` | меняются на месте | панель перезапускает машину сама |
| `disk_mib` | меняется на месте | только увеличение; раздел растягивается в госте |
| `password` | меняется на месте, секрет | root (Administrator у Windows), латиница |
| `ipv4`, `ipv4_addresses`, `state`, `os_name`, `node` | вычисляются | |

Создание ждёт, пока машина станет `active`: адрес и пароль уже настроены.
Сорвалась сборка — ресурс помечается на пересоздание.

Импорт существующей машины по номеру из `/vm/v3/host`:

```bash
terraform import vmpanel_vm.web 42
```

Система восстанавливается по названию. Пароль панель не хранит, поэтому
первый `apply` после импорта установит пароль из конфигурации.

### `vmpanel_webhook`

`url` (только https и внешний адрес), `events` (`["*"]` — все), `description`,
`active`; вычисляется `secret` — ключ подписи `X-Webhook-Signature`. Его
панель отдаёт только при создании, поэтому он есть в состоянии лишь у
вебхуков, созданных этим провайдером.

## Справочники

`vmpanel_os`, `vmpanel_location`, `vmpanel_preset` — поиск по `name` без учёта
регистра. Отдают `id`, у систем — `state`, у тарифов — `cpu`, `ram_mib`,
`disk_mib`. Не нашлось — ошибка со списком того, что есть.

## Сборка

```bash
go vet ./... && go test ./... && go build -o terraform-provider-vmpanel .
```

Для локальной проверки — `dev_overrides` в `~/.terraformrc`:

```hcl
provider_installation {
  dev_overrides { "fedeko-dev/vmpanel" = "/путь/к/каталогу/с/бинарником" }
  direct {}
}
```

ключ подписи — [signing-key.asc](signing-key.asc), отпечаток
